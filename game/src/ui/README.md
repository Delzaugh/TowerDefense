# Player interface

For semantic panels such as a `section` or `aside`, apply the shared `ui-surface` class directly and keep its layout in screen CSS. Portrait and item choices can compose the shared quiet `Button` with their own content layout; its pressed state supplies the selection treatment.

Responsive HUD, menus, tower/Persona panels, wave and boss previews, tutorial prompts, save controls, and run debrief. Read session view data and issue commands. Support touch and non-colour-only feedback; React never advances or mutates the simulation.

The Field kit foundations live in `toolkit/index.tsx`. Import `Button`, `IconButton` (requires an accessible label), `Surface`, `Input`, `Select`, `SegmentedControl`, `StatGauge`, `StatusBadge`, and `ThemePicker` for shared controls. Buttons, surfaces, inputs, and selects pass through native attributes and refs. `Input` defaults to text; checkbox/radio types receive `.ui-checkbox` styling and need a labeled 44px touch area supplied by the screen. Inputs/selects use `.ui-input`, with 16px text on coarse pointers. Keep screen layout in screen CSS; these components own appearance, focus, disabled, and touch target states. Segments are a labeled group of pressed buttons; gauges are noninteractive accessible meters, with optional qualitative segmented fills via `segments`, `showValue={false}`, and `valueText`. Use Octicons from `@primer/octicons-react`, and name icon-only controls by action.

`ThemeProvider` wraps the application once. `useTheme()` exposes `preference`, `resolved`, `setPreference`, and a storage `notice`. Appearance defaults to Dark, persists under `tower.ui.appearance.v1`, supports Light and System, follows device changes in System mode, and synchronizes other browser tabs. Blocked storage keeps selection usable for the visit. `ThemePicker` labels the native select and renders the notice. Themes change the HTML `data-theme` attribute and native color scheme; they do not change authored world lighting or simulation state.

Semantic CSS tokens: `--ui-bg`, `--ui-surface`, `--ui-raised`, `--ui-fg`, `--ui-muted`, `--ui-border`, `--ui-accent`, `--ui-accent-soft`, `--ui-primary`, `--ui-primary-hover`, `--ui-on-primary`, `--ui-positive`, `--ui-attention`, `--ui-danger`, `--ui-shadow`, `--ui-radius`, `--ui-focus`, and `--ui-backdrop`. Use `--ui-world-fg` and `--ui-world-muted` for text directly over the 3D world; these remain light in both themes. Mona Sans is the shared interface font. Controls have 6px corners and 44px minimum height across input types; surfaces use the 8px radius token. Keep primary green sparse for the next meaningful action.
