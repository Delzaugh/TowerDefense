# GitHub office research, model kit and disposable campus

Completed 2026-09-30. The public research pack contains35 curated sources,84 reference images and three PDFs. The new original kit contains29 canonical editable Blender scenes and29 self-contained GLBs, with versioned contracts, recipes, packed palettes, provenance and current author reviews. Geometry is a friendly low-poly interpretation of GitHub office references, with some original campus landscape additions.

## Limits and disposal

No complete measured Brannan CAD/floor-plan package was found. Campus layout and most dimensions are inferred; the historical50ft building height and documented1ft membrane assembly are explicit source cues. This combines several historical/current design phases, not a claim about one current office fit-out. Static environment kit with camera tours, not a collision-based walking simulation. Source photographs are references rather than runtime textures. Marks/reference artwork retain their owners' rights.

Stop the preview server, then remove only `prototypes/github-campus/` to discard the prototype. Canonical Blender sources, runtime GLBs, catalog and research pack remain outside it.
