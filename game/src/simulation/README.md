# Authoritative simulation

Pure TypeScript level state, commands, events, queries, and fixed-step rules. Own movement, targeting/occlusion, tower configuration, aura effects, work/problem outcomes, economy, debt, waves, boss state, and victory/failure. Export serializable snapshots and restore validation.

Use validated content data and deterministic inputs. Never import React, Three.js, browser APIs, storage, audio, or session/app modules. Split into system folders when implemented files warrant it; future gameplay layers are not reserved here.
