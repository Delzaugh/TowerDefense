# Analyst accessory concepts

User found the goggles aggressive and requested six creative alternatives for selection. Pale teal colour direction stays; all alternatives remove eye coverings and pointed owl brows. These are concept alternatives only; the production model has not been changed.

Six directions: Data Fan (data distribution), Prism Reader (decomposition), Orbit Mapper (relationships), Index Keeper (cataloguing), Pattern Sprout (pattern connections), Insight Cap (interpretation).

The concept artwork is illustrative, with a design target below 2,500 triangles rather than a measured mesh count. Built-in image generation, bundled six-panel template and exact label overlay. Selection remains with the user.
