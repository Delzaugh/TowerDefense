# GitHub monument sign

User direction, 2026-09-30: create reusable GitHub office/campus models and a disposable assembled prototype.

## Reference and primary form

Official current white GitHub lockup sampled directly from downloaded vector outlines, preserving relative proportions and negative spaces; independently authored graphite monument slab. Branding is source reference and remains GitHub property.

Research references: exterior-01.webp, report.html. Exact as-built office measurements are unavailable; this is an original friendly low-poly interpretation. The requested target size is approximately 5 × 2.8 × 0.5 metres in X/Y/Z; furniture ensembles may have slight practical variation. Resolve broad body silhouette, repeated rhythm and real negative spaces before fittings.

## Interfaces and delivery

Center X/Z; floor contact Y=0; front+Z. Static environment, no rig or invented clips. All component transforms joined/applied beneath root. One 64×4 packed palette texture with deliberate padded swatches, no photo textures. Opaque plate treatment is an intentional readability/performance interpretation for suspended contribution art. Author review and technical validation are separate; explicit user acceptance remains pending.
