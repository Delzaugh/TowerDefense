# Architect: shape evolution from Copilot Base

## User correction

The previous three ideas were rejected as recolors. The user explicitly allows the body shape to change and the goggles to be dropped. Base is an evolutionary ancestor, not a geometry template. Preserving goggles, ear outlines, or exact Base proportions is not a user requirement.

## Delivered concepts

- **01 Keystone**: broad, low body; continuous arch with deep side buttresses and small openings; no goggles.
- **02 Cantilever**: offset projecting face and asymmetrical folded body; integrated drafting cassette. Final image lowers the first draft's fin-like rear crest.
- **03 Nexus**: tapered central face/core and much larger interlocking side volumes; software components inhabit the side cavities. No goggles.

All are concepts generated with the built-in image tool, pending user selection. Base v02 runtime `validation/iso.png` was supplied only as the ancestor reference; prior recolor concepts were not supplied. Canonical Blender and GLB remain r27. The generated front views and silhouette studies are illustrative, not measurements or masks derived from production geometry. Nexus's silhouette retains stylized eye/cavity cutouts; its exact openings and repeated module count would be resolved in modeling.
