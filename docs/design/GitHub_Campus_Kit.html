Reusable environment art · v01

GitHub campus kit

36 editable models bring together the warm warehouse, orange container studios, pale oak reading niches, luminous meeting walls, rooftop concrete furniture contribution-green artwork, bookshelf work lounges and authored mural panels informed by the research.

Open campus prototypeResearch and photographsDetailed inventoryDownload complete pack

This is an original low-poly interpretation of several GitHub office design phases. It is not a measured replica. Assets are static and use embedded palette textures. GLB axes are Y up / Z front; Blender sources use Z up / minus-Y front. Furniture ensembles remain editable meshes in Blender. The prototype provides camera exploration, not a collision-based walk simulation.
