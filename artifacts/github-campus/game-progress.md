# GitHub campus kit and disposable prototype

User intent: research real GitHub offices, then create the complete reusable 3D office/campus kit and a removable campus prototype using it.

Research complete: 35 sources, 84 photographs, three public reference PDFs. Source-backed report: docs/research/github-offices-2026-09-30/report.html.

Art direction: original chunky low-poly geometry, warm exposed timber, light stucco warehouse arches, orange corrugated container studios, pale oak library, contribution-green atrium and recognizable official GitHub identity. Campus is an interpreted combination of documented design phases, not an as-built reconstruction.

Production complete: 29 assets in authoritative catalog. Lead owns eleven floor, structural and site models plus integration; architecture worker owns eight building modules; props worker owns ten furniture/art/signage modules. Prototype worker owns only prototypes/github-campus. All Blender sources and runtime GLBs stay outside the removable prototype folder. No gameplay source modifications.
