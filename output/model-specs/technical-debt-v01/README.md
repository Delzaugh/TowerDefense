# Technical debt ledger concept specifications

Selected source: output/concepts/technical-debt-v04/technical-debt-ledger-sheet.png, options 01 and 02.

- Option 01: Deferred Fixes, open ledger with code, unfinished tasks and overdue clock.
- Option 02: Shortcut Register, closed ledger with patched code emblem and debt tabs.
- Preserve the user's direction: administrative technical debt, visibly dirty, smelly and neglected; broad low-poly grime, yellowed pages and olive mildew.
- These sheets were generated with built-in imagegen from concept references. Side and rear views are proposed design interpretations, not renders of a verified production mesh.
- Wireframes are illustrative. No production mesh, measured statistics, UV layout or texture atlas was available. Unknown fields are shown as dashes and UV grids remain empty.
- Target under 2,500 triangles is a concept design ceiling, not a measured count.
- Stink wisps and ground grime effects are separate presentation effects.
