# Cohesion Pack model specification

User selected People Manager concept option 02 from the second variants and requested a model spec sheet with the neck lanyard removed. The neck cord and badge are removed; functional teal backpack straps remain.

Source design: design/concepts/people_manager/v02/people_manager_artwork_v02.png, top-center concept. Built-in image generation uses the bundled model-spec-sheet template. Prompt retained alongside deliverable.

Five pyramid levels use the Lencioni-inspired positive sequence from broad base to apex: trust, constructive conflict, commitment, accountability, shared results. Tier colors: teal, blue, purple, coral, amber. Source for model sequence: https://www.tablegroup.com/topics-and-resources/teamwork-5-dysfunctions/

This sheet develops previously unseen side and rear construction as proposed concept geometry. It is not a measured Blender asset. Wireframe is illustrative, UV grid is intentionally empty, and triangle, vertex, texture and material values remain unknown. Under 2500 triangles is the inherited concept design target, not a verified result.
