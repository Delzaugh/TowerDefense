# Delivering a coherent revision

1. Keep a focused decision record of user choices and reference provenance. Update the manifest for an intentional contract change. Breaking clip, anchor or rig interfaces need a new version or a coordinated presentation/runtime change.
2. Apply the refinement to the editable Blender source or its authoritative recipe. A copied inspector note identifies the asset, version, revision/hash, camera, clip/time, part and temporary palette changes. Check those values against the current revision before applying it.
3. Run the shared guarded export. It preserves previous source/export milestones, associates evidence with file hashes and promotes only a passing candidate. A failure is a failure even if another command succeeds later. Inspect its report; fix the source/contract rather than suppressing a blocking check.
4. Refresh the existing shared inspector tab rather than opening duplicates. Preserve camera and clip context when compatible. Compare registered runtime assets or versions at authored scale with the same lighting. Source snapshots remain offline. Personally inspect the exported GLB using the affected-part views and states in [shape-details.md](shape-details.md), then at phone scale. Technical promotion does not complete this visual review; fix visible defects in scope, re-export and review the replacement before reporting completion.
5. Deliver the source, runtime export and shared preview link, with a concise account of the change and checks. Report remaining artistic judgments honestly; neither numerical validation nor a clean browser console constitutes user approval.

Use milestones for meaningful comparisons, not every temporary experiment. Keep staging, logs, references, evidence and renders outside runtime. Register canonical source/runtime paths explicitly and enforce the category/id/version layout from assets/README.md. Update consumers and validation records together for an intentional migration. Use the optional read-only reviewer only when independent review is requested, passing the exact manifest/revision, references and evidence. It should return actionable findings with a view or timestamp, not edit the scene.
