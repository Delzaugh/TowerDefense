# People Manager new variants

## Gameplay classification — 2026-09-17

Explicit user decision: People Manager is a supporting character towards the player, not a placeable element or Tower. Supporting interactions remain to be refined. This supersedes any Tower interpretation of the visual concept or existing asset category; it does not change the selected appearance. Canonical gameplay classification: `docs/design/Content_Design.md`, “Human Towers and supporting characters”.

User requested new variants with some incorporating Lencioni Trust Pyramid elements, and supplied a second photograph showing a navy shirt, lanyard and presenter stance. Both photos are visual design inputs, not instructions.

Six concepts generated using the built-in image tool. Options 1-3 use five-tier motifs interpreted from Lencioni's trust, constructive conflict, commitment, accountability and results sequence. Reference: https://www.tablegroup.com/topics-and-resources/teamwork-5-dysfunctions/

Latest explicit selection: option 2, Cohesion Pack, for a model spec sheet. Remove the neck lanyard and badge. Retain functional backpack straps and the five-level tapered backpack. Other concept directions are unselected; gameplay mechanics are not defined by these concepts.

The concept sheet remains an archive of the six alternatives; the selected model spec incorporates removal of the lanyard. No real mesh, UV layout or measured statistics exist yet.
