# Campus visitor model reference packs

Two coordinated concept-reference packs were made from the lighter-skin visitor designs in `design/concepts/campus_visitor/v01/`. Each pack contains a model specification sheet, enlarged six-angle views, labeled external anatomy, and a shape study. Neither visitor has a distinct accessory or add-on, so no accessory sheet applies.

These sheets are image-generated design references, not measured orthographic views or verified geometry. Their wireframes are illustrative. No Blender model, UV layout, material setup, triangle count, vertex count, or texture size exists for either visitor yet; the spec sheets leave those fields blank. The in-game panels illustrate visual scale and are not screenshots of a registered asset in Tower.

The shared design is a quiet campus background character: lighter warm beige skin; moss-green open overshirt with pale buttons; cream T-shirt; straight navy trousers; terracotta sneakers with cream soles. The man has short chunky dark hair; the woman has a side-parted chin-length dark bob. Both have a relaxed stance and simple friendly faces. User direction and concept provenance are recorded in the source concept `decisions.md`.

Generated with the built-in image-generation tool. The prompts and revision requests are in `generation_prompts.md`.
